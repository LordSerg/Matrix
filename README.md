# Technology used
C#, WindowsForms, math, algorithm

# Overview
In program I realised some simple actions on one matrix:
1. [Determinant of a matrix](https://en.wikipedia.org/wiki/Determinant)
2. [Transpose of a matrix](https://en.wikipedia.org/wiki/Transpose)
3. [Matrix to the power of n](https://matrix.reshish.com/power.php)
4. [Invertible matrix](https://en.wikipedia.org/wiki/Invertible_matrix)
5. [Multiply matrix by scalar n](https://www.khanacademy.org/math/precalculus/x9e81a4f98389efdf:matrices/x9e81a4f98389efdf:multiplying-matrices-by-scalars/a/multiplying-matrices-by-scalars)
6. [Multiply](https://en.wikipedia.org/wiki/Matrix_multiplication) the transposed matrix by the original $\left( A^t\cdot A\right)$
7. [Multiply](https://en.wikipedia.org/wiki/Matrix_multiplication) the original matrix by the transposed $\left( A\cdot A^t\right)$
8. [Adjugate matrix](https://en.wikipedia.org/wiki/Adjugate_matrix)
9. [Rank of the matrix](https://en.wikipedia.org/wiki/Rank_(linear_algebra))
